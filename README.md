SIGPAC — Plateforme Mobile Sécurisée

SIGPAC est une solution Android dédiée à la gestion et au suivi des dossiers de plaintes pour le Pôle Anti-Corruption (PAC) à Madagascar.



Objectif du projet

Moderniser et sécuriser le processus de dépôt de plaintes afin de garantir la transparence et l'efficacité du traitement des dossiers institutionnels.



Stack Technique

Mobile : Java (Android Studio)

Backend : API REST & PostgreSQL



Fonctionnalités Clés

Authentification & Profil : Gestion sécurisée des comptes utilisateurs.

Dépôt de Plaintes : Déclaration simplifiée avec option d'anonymat.

Suivi & Filtrage : Consultation en temps réel et recherche avancée via filtres.

Statistiques : Visualisation des données pour une meilleure aide à la décision.

Exportation : Génération de rapports au format PDF.
